# PVE Lite Dashboard — 资源条与状态显示

## 资源条

CPU 资源条的填充宽度为 CPU 使用率，内存资源条的填充宽度为已用内存除以分配内存。节点和实例使用同一规则，轨道始终占满所在布局的宽度。填充比例限制在 0–100% 之间，文字展示原始数据格式化后的结果。

资源条以颜色表示使用率区间：正常、警告、危险。默认 CPU 警告阈值为 70%、危险阈值为 90%；内存分别为 75% 和 90%。达到阈值时切换颜色，阈值可在页面设置中调整，取值范围为 0–1，警告值必须小于危险值。内存正常状态使用蓝色，CPU 正常状态使用绿色。轨道使用统一的中性底色。

## 实例状态

实例状态始终保留文字标签。运行、挂起、停止和模板分别使用对应的状态标识。`src/core/config.ts` 中的 `vmStateDisplay` 定义每种状态是否展示 CPU 与内存资源条，以及挂起状态的内存颜色。

资源占用颜色依据原始使用率判断。状态颜色与资源占用颜色分别表达不同信息，避免只依靠颜色判断状态。

## 数据边界

CPU 使用率取 PVE 返回的比例值。内存占用率在分配内存大于零时计算为 `mem / maxmem`，否则按零处理。显示时将异常或越界比例限制在 0–1，避免资源条溢出。
